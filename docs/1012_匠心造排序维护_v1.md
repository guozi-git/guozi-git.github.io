# 匠心造排序与新增

文章资料维护在 `src/lib/atelier-papers.json`，页面自动生成全部档案封面和详情。

- `priority`：手动展示优先级，非负整数，越小越靠前；不填写则放在已设置优先级的文章之后。同优先级按收藏编号升序。
- `collectionNumber`：永久收藏编号，正整数且不能重复，新增文章使用新的编号。改变展示位置时不要修改此编号。
- `id`：永久文章 ID，与详情网址、PDF 对应，不因排序而更改。
- `coverLines`：封面标题分行；`coverTopic`：封面简短分类。详情仍使用 `originalTitle`、`topic`。

建议优先级以 100、200、300 等间隔设置。需要插到两篇中间时可用 150，不必重排全部资料。当前 P089 优先级为 100，收藏编号为 1。

例如把某篇放到 P089 前面，将其优先级设为 50；放到后面则设为 200。优先级与研究水平评分独立，不会修改评价结果。

新增文章时追加完整资料和原文 PDF，同步 `scripts/public-assets.json`，运行内容检查、构建与浏览器检查。页面不提供访客修改排序的按钮。调整 JSON 后需重新构建；正式发布仍须用户确认。
